青蛙阅读（蛙阅）0.0.7 基于 KNITIPKA 的 FrogReader，以 GPL-3.0-only 发布。

## 更新内容

- 损坏的 EPUB 也能读了。以前书籍文件里只要有一章的压缩数据坏掉，整本书就打不开，只显示「文件可能已损坏或丢失」。现在解析器会跳过读不出来的章节，其余章节照常阅读；翻到损坏的位置时显示「本章内容损坏」的提示，下面有按钮可以直接跳到最近的可读章节。
- 章节目录里损坏的章节仍然保留，点进去看到的就是提示卡，不会悄悄少一章。

## 安装与校验

- 需要 Android 8.0 或以上版本。应用包名为 `github.wzk0.frogreader`，版本代码为 13。
- 同签名的青蛙阅读正式版可直接覆盖升级。若当前安装的是调试版，请先备份数据和书籍，再卸载调试版并安装正式版。
- 下载 APK 和同一版本的 `SHA256SUMS.txt` 后，运行 `sha256sum -c SHA256SUMS.txt` 校验。
- [源码与问题反馈](https://github.com/wzk0/frog-reader) · [上游项目](https://github.com/KNITIPKA/frog-reader)

## 升级说明

- 之前因为数据损坏而完全打不开的书，升级后可以打开并读可读的部分；缺的章节内容无法恢复，需要重新下载完好的文件。
- 预解析仍受缓存上限约束：正文序列化后超过约 8 MB（压缩）/ 64 MB（展开）的书会提示「未能保存完整缓存」，重新打开时重新解析一次，不影响阅读。
- OPDS 支持公开目录的浏览、搜索和直接下载；需要登录、借阅、购买或 DRM 的链接暂不支持。
