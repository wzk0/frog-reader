青蛙阅读（蛙阅）0.0.4 基于 KNITIPKA 的 FrogReader，以 GPL-3.0-only 发布。

## 更新内容

- 在线搜书改用 OPDS。支持添加目录链接、从 Atom 或 OPDS JSON 文件导入目录地址、测速、跨目录搜索、浏览子目录和翻页。下载进度在图书条目内显示，可取消下载，已下载图书加入书库。
- 书库和书架的书籍长按菜单新增「预解析」，可在后台解析全书并查看进度和缓存状态。分页模式会优先排版目录跳转的目标章节，并复用已排好的完整章节。
- 阅读设置新增字重、字间距和反向点按翻页。长按字号、行距等设置的当前值可恢复默认。
- 统一编辑框的圆角描边样式，调整搜索结果卡片和加载动效。米色主题下，底部导航选中项与浮动添加按钮使用对比度更高的棕色。

## 安装与校验

- 需要 Android 8.0 或以上版本。应用包名为 `github.wzk0.frogreader`，版本代码为 10。
- 同签名的青蛙阅读正式版可直接覆盖升级。若当前安装的是调试版，请先备份数据和书籍，再卸载调试版并安装正式版。
- 下载 APK 和同一版本的 `SHA256SUMS.txt` 后，运行 `sha256sum -c SHA256SUMS.txt` 校验。
- [源码与问题反馈](https://github.com/wzk0/frog-reader) · [上游项目](https://github.com/KNITIPKA/frog-reader)

## 升级说明

- 旧版规则书源需在设置中改用 OPDS 目录。已下载的书籍可以继续阅读。
- OPDS 支持公开目录的浏览、搜索和直接下载。需要登录、借阅、购买或 DRM 的链接暂不支持。
