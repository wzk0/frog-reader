FrogReader 中文分支的**第一个 v 版本**，基于上游 BETA 2（作者 KNITIPKA）构建。

## 本版本修复

- **继续阅读回到了正确的位置**：阅读进度现在同时保存页首字符（`charOffset`），重开时用「条目 + 字符」精确定位；
  打开瞬间的前缀分页/分页器快速通道即使被夹断，也不会再把这个错误位置写回存档。
- **书库卡片的进度与页码和阅读器一致**：已读百分比、本章还剩页数改为按阅读器自己的分页坐标计算
  （以前按段落序号算，页码与书库对不上）。
- **书架可以排序**：书架标题右侧 ⋮ 菜单新增「按最近阅读 / 按文件名」，按文件名时 `01 < 02 < 10` 自然排序，
  选择保存在该书架自身（`Shelf.sortMode`），旧书架默认保持原顺序。

## 本分支既有功能

- 完整简体中文界面（含弹窗、错误提示；`locales_config` 声明 zh）。
- 书库排序：最近阅读 / 文件名 / 按文件夹分组（组内按文件名自然排序）。
- 扫描文件夹归档：有子文件夹时可一键为每个子文件夹建同名书架；无子文件夹时可把整个文件夹放进一个同名书架。
- 在线字体：霞鹜文楷 / 霞鹜新致宋 / 霞鹜新晰黑 / 思源宋体 / 思源黑体 / MiSans / 得意黑，下载后自动启用。
- 触感修复：长按不再双震，成功提示不再重复震动（失败仍提示）。
- 关于页：GitHub、版本发布、问题反馈均指向本仓库，上游作者单独署名。

## 安装与升级

- 包名 **`github.wzk0.frogreader`**，版本 code **7**、name **0.0.1**。
- 从本仓库此前的 `beta-2-zh`（code 6，同一把签名密钥）可以**直接覆盖升级**。
- 从上游 `knitipka.frogreader` 或任何 debug 包切换过来需要先卸载；卸载会清空应用内数据，
  请在旧版本里「设置 → 备份 → 立即备份（数据与书籍）」后，再于新版「从备份恢复」。

## 校验

```bash
sha256sum -c SHA256SUMS.txt
```

签名证书：`CN=github.wzk0.frogreader, OU=Android, O=wzk0, C=CN`

## 已知限制

- 字体下载需要联网（GitHub / jsDelivr / 小米 CDN），国内网络可能需要代理。
- 「复制诊断信息」生成的报告仍是英文（给上游排查用的技术文本）。
- 其余限制与上游 BETA 2 相同：不支持 PDF / KFX / DRM / 固定版式 EPUB。
