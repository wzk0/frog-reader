青蛙阅读（简称蛙阅）0.0.2。本版本基于 KNITIPKA 的 FrogReader，继续以 GPL-3.0-only 发布。

## 更新内容

- 书库、阅读设置、导入和个人页等常用列表统一为连体卡片。调整浅色、米色和深色主题下的菜单、弹窗与控件配色，移除界面投影。
- 重新设计底部导航，点击后立即更新选中项。新增按钮与导航指示器使用同一主题色。
- 书架默认跟随书库排序，也可以单独指定排序。旧版保存的「最近阅读」无法区分默认值和手动选择，升级后按「跟随书库排序」处理。
- 每日目标刻度默认展开。移除书籍、删除书架及书籍、从选择弹层移入书架的确认操作各触发一次触感。

## 安装与校验

- 包名为 `github.wzk0.frogreader`，版本号为 0.0.2，版本代码为 8。
- 同签名的本仓库正式版可直接覆盖升级。若从调试包或上游应用迁移，请在旧应用里先备份数据和书籍，再到正式版恢复。
- 下载 APK 和 `SHA256SUMS.txt` 后，用 `sha256sum -c SHA256SUMS.txt` 校验。
- [源码与反馈](https://github.com/wzk0/frog-reader) · [上游项目](https://github.com/KNITIPKA/frog-reader)

## 已知限制

- 首页卡片与列表切换的控制行高度已固定。调试包真机上仍观察到切换卡顿，正式版表现待确认。
