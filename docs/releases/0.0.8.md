青蛙阅读（蛙阅）0.0.8 基于 KNITIPKA 的 FrogReader，以 GPL-3.0-only 发布。

## 更新内容

- 设置里新增「储存」，位于备份下方。可以按书籍查看每个源文件占多少空间并直接删除（会一并移除该书的摘录、书签、评分和阅读进度，有二次确认），也可以查看正文图片、排版、解析三类缓存各自的大小并一键清理。清理只影响能重新生成的内容。
- 预解析加了二次确认：这本书已经完整解析并缓存过时，再点预解析会先询问是否重新解析，而不是默默再跑一遍并覆盖现有缓存。第一次预解析仍然直接开始。
- 解析缓存的上限放宽，长篇小说也能用上预解析缓存：压缩快照 8 MB → 16 MB、展开快照 64 MB → 96 MB、单本缓存占位 8 MB → 16 MB、已解析总预算 64 MB → 128 MB、缓存总预算 128 MB → 256 MB。此前十几 MB 正文的小说会提示「未能保存完整缓存」，现在通常可以正常缓存。
- 储存页的移除与数字都带过渡：删除书籍时行会收起、其余行平滑上移、首尾圆角跟着变形；顶部占用数字滚动变化，占用比例的进度条与预解析对话框同款并在刷新时平滑过渡。

## 安装与校验

- 需要 Android 8.0 或以上版本。应用包名为 `github.wzk0.frogreader`，版本代码为 14。
- 同签名的青蛙阅读正式版可直接覆盖升级。若当前安装的是调试版，请先备份数据和书籍，再卸载调试版并安装正式版。
- 下载 APK 和同一版本的 `SHA256SUMS.txt` 后，运行 `sha256sum -c SHA256SUMS.txt` 校验。
- [源码与问题反馈](https://github.com/wzk0/frog-reader) · [上游项目](https://github.com/KNITIPKA/frog-reader)

## 升级说明

- 缓存放宽后，之前提示「未能保存完整缓存」的书籍可以重新预解析一次，之后重新打开会直接读取缓存。
- 储存页删除书籍不可撤销；只想清理可再生数据时请用「清理全部缓存」，不会动书籍文件、封面与阅读进度。
- OPDS 支持公开目录的浏览、搜索和直接下载；需要登录、借阅、购买或 DRM 的链接暂不支持。
