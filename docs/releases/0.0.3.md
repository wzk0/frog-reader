青蛙阅读（蛙阅）0.0.3 基于 KNITIPKA 的 FrogReader，以 GPL-3.0-only 发布。

## 更新内容

- 新增书源订阅。可以从本地 JSON 或链接导入，按订阅查看和管理书源，支持全量测速和单订阅测速，保留响应时间与连通状态。
- 书源支持右滑收藏、左滑打开删除确认，也可以长按后批量收藏或移除。搜书时可选全部已启用书源、收藏或单个订阅。
- 在线搜书支持滚动进度日志、取消搜索和分类筛选。可同时下载最多三本书，其余排队。再次点按条目可取消下载，下载完成的书会加入首页书库。
- 改善常见书源规则兼容性，补上目录和正文分页，并分别提示连接失败、目录缺失、正文缺失和规则不支持。
- 统一设置子页、书源订阅、摘录与书签等页面的预测性返回转场。首次启动设置采用连体卡片，分组标题采用统一间距。
- 分类标签改为无描边的单行圆角样式。恢复浮动添加按钮的 Material 阴影。阅读记录通过条目操作移除，列表内的滑动删除入口已移除。

## 安装与校验

- 需要 Android 8.0 或以上版本。应用包名为 `github.wzk0.frogreader`，版本代码为 9。
- 同签名的青蛙阅读正式版可直接覆盖升级。调试包与正式版签名不同，请先备份数据和书籍，再卸载调试包并安装正式版。上游应用可通过备份迁移。
- 下载 APK 和同一版本的 `SHA256SUMS.txt` 后，运行 `sha256sum -c SHA256SUMS.txt` 校验。
- [源码与问题反馈](https://github.com/wzk0/frog-reader) · [上游项目](https://github.com/KNITIPKA/frog-reader)

## 已知限制

- 书源规则支持常见的 CSS、XPath、JSON 取值和分页。依赖 JavaScript、WebView 或登录的规则可能无法使用。
- 书源和字体预设下载需要网络。已下载的书籍和本地书库可以离线使用。
