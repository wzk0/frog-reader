青蛙阅读（蛙阅）0.0.5 基于 KNITIPKA 的 FrogReader，以 GPL-3.0-only 发布。

## 更新内容

- 导入 TXT 时按 UTF-8、GB18030、Windows-1251 的顺序探测编码。此前只有 UTF-8 与 Windows-1251 两条路径，网页常见的 GBK 小说会停在「无法添加图书」，现在可以直接导入。
- TXT 体积上限从 16 MB 提到 64 MB。一本 38 MB 的合集（约 1360 万字）可以直接导入，打开时排版会慢一些。
- 文本中偶发的控制字符（例如六百多万字里夹杂的一个）不再让整本被判为「二进制文件」而被拒；只有占比达到千分之一以上才会拒绝。
- OPDS 导入按钮的提示文案改为「从 Atom 或 OPDS JSON 文件添加目录」。

## 安装与校验

- 需要 Android 8.0 或以上版本。应用包名为 `github.wzk0.frogreader`，版本代码为 11。
- 同签名的青蛙阅读正式版可直接覆盖升级。若当前安装的是调试版，请先备份数据和书籍，再卸载调试版并安装正式版。
- 下载 APK 和同一版本的 `SHA256SUMS.txt` 后，运行 `sha256sum -c SHA256SUMS.txt` 校验。
- [源码与问题反馈](https://github.com/wzk0/frog-reader) · [上游项目](https://github.com/KNITIPKA/frog-reader)

## 升级说明

- 已导入的书籍不受影响。GBK 文件、超过 16 MB 的文件、以及混入控制字符的文件，此前导入失败时会提示格式不受支持，重新导入即可。
- 旧版规则书源仍需在设置中改用 OPDS 目录。OPDS 支持公开目录的浏览、搜索和直接下载；需要登录、借阅、购买或 DRM 的链接暂不支持。
