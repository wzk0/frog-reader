# 青蛙阅读 · 蛙阅

青蛙阅读是 [FrogReader](https://github.com/KNITIPKA/frog-reader) 的简体中文分支，一款面向 Android 的开源电子书阅读器。可以把本地书籍整理进书架，按书调整排版，并用阅读记录、摘录和书签保存自己的阅读轨迹。本地书库和阅读功能无需账号，断网也能使用。OPDS 目录浏览、图书下载和字体预设下载需要联网。

[下载 APK 与查看更新说明](https://github.com/wzk0/frog-reader/releases) · [反馈问题](https://github.com/wzk0/frog-reader/issues)

## OPDS 目录与在线搜书

1. 在 **设置 → OPDS 目录** 添加目录链接。也可导入包含在线地址的 Atom 或 OPDS JSON 文件。目录可启停、移除或测速，测速结果会保留。
2. 在首页通过添加按钮打开 **浏览与搜索 OPDS**。本地书库搜索无匹配时，也可以转到 OPDS 搜索。搜索会查询所有已启用的目录。
3. 目录支持分组、子目录和分页。目录提供搜索时，可以按书名、作者或关键词发起请求。
4. 点按可下载图书即可加入首页书库。若有多个支持的格式，先选格式。下载排队或进行中可再次点按取消。已下载的图书可以离线阅读。

兼容 [OPDS 1.2 Atom 目录](https://specs.opds.io/opds-1.2) 和 [OPDS 2.0 JSON 目录](https://specs.opds.io/opds-2.0) 的公开浏览、搜索和直接下载流程。需要登录、借阅、购买或 DRM 的链接暂不支持。旧版规则书源需要换成 OPDS 目录链接，已下载的图书可以继续阅读。

## 在原版基础上的改动

- **简体中文界面**。书库、阅读器、设置、导入向导和错误提示均已本地化，应用名称改为「青蛙阅读」。
- **按文件夹整理书库**。扫描文件夹时，可以把子文件夹分别建成书架，也可以把整个平铺文件夹导入同一个书架。
- **按原文件名和来源文件夹排序**。书库支持按最近阅读、文件名和文件夹排序，文件名按数字自然排序，例如 `2 卷` 排在 `10 卷` 前。书架默认跟随书库，也可单独指定排序。
- **中文字体预设**。在阅读设置中可下载并启用霞鹜文楷、霞鹜新致宋、霞鹜新晰黑、思源宋体、思源黑体、MiSans 和得意黑。字体下载需要联网，下载后的字体可离线使用。
- **更准确的阅读进度**。继续阅读会尝试回到上次保存的页首字符位置。书库的已读百分比和本章剩余页数使用阅读器的分页结果。
- **界面和触感调整**。书库列表、设置、导入和阅读记录等页面使用连体卡片。底部导航只显示选中项的文字，添加按钮使用同一强调色。菜单和弹窗采用更清晰的底色，筛选标签使用无描边的圆角样式，首次启动设置和常用页面采用连体卡片与一致的标题间距。支持预测性返回的 Android 系统上，设置子页、书架和阅读器等界面会随返回手势移动，取消手势会回到原位。

## 阅读与管理

- **阅读器**支持分页和连续滚动，可切换浮动或经典控件，并为每本书调整字体、字号、字重、字间距、行距和页边距。长按数值可恢复默认。分页模式可交换左右点按区域。支持书内搜索、章节目录、脚注和跳转后返回。
- **阅读计划与阅读记录**可以记录电子书、纸质书和在其他应用中读的书。阅读记录支持阅读日期、评分、书评和重读记录。
- **摘录与书签**可以保存高亮、笔记和书签，并在「我的」页查找或跳回原文。每日目标刻度常驻显示。
- **备份**支持仅备份数据或同时备份书籍，也可设置自动备份。

## 支持的格式

| 格式 | 支持范围 |
| --- | --- |
| EPUB 2/3 | 流式排版、目录、图片、嵌入字体及部分出版样式 |
| FB2 / FB2 ZIP | 章节、注释、诗歌和嵌入图片 |
| MOBI / KF8 / AZW3 / PalmDoc | 支持的 Kindle 文本及资源结构 |
| TXT | UTF-8、带标记的 UTF-16 及部分旧式编码 |
| Markdown | CommonMark、表格和按标题导航 |

复杂出版样式可能与原版式有差异。当前不支持 PDF、KFX、带 DRM 的书籍和完整固定版式 EPUB/KF8。

## 安装与升级

需要 **Android 8.0 或以上版本**。在本仓库的 [GitHub Releases](https://github.com/wzk0/frog-reader/releases) 下载 APK。应用包名为 `github.wzk0.frogreader`。

- 同签名的青蛙阅读正式版可以直接覆盖升级。
- 从调试包或上游 FrogReader 迁移时，请先在旧应用中进入 **设置 → 备份**，导出数据与书籍。安装正式版后，再从备份恢复。调试包与正式版同包名但签名不同，切换前需在确认备份可用后卸载调试包。
- 下载 APK 和同一版本的 `SHA256SUMS.txt` 后，可用 `sha256sum -c SHA256SUMS.txt` 校验文件。

## 从源码构建

项目使用 Kotlin、Jetpack Compose 和 Material 3。构建需要 **JDK 21** 和 **Android SDK 37**。

```sh
git clone https://github.com/wzk0/frog-reader.git
cd frog-reader
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

调试 APK 位于 `app/build/outputs/apk/debug/`。构建、签名和贡献流程见 [贡献指南](CONTRIBUTING.md)，上游历史见 [更新日志](CHANGELOG.md)。
